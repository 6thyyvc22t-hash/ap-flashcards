# 応用情報 科目B — 追加・編集・削除できるデジタル単語帳

更新日：2026-11-22

## 構成

- `index.html` — 画面・学習 UI。問題数や本文は一切ハードコードしない。
- `app.js` — 採点、復習、学習記録、問題管理、データ検証。
- `styles.css` — iPad・スマホ向け表示スタイル。
- `questions.json` — 全問題と削除済みの保管データ。初期状態は150問。

## 使用開始（iPad + GitHub Pages）

1. 新しく **Public** リポジトリ `ap-flashcards` を作る。既存のPrivate `my-knowledge-base` を公開しないこと。
2. 4ファイルをリポジトリの最上位に同時にアップロードする。ZIPそのものをアップロードしない。
3. GitHub `Settings` → `Pages` → `Deploy from a branch` → `main` / `(root)` を選択。
4. `https://6thyyvc22t-hash.github.io/ap-flashcards/` をSafariで開く。
5. 共有 → ホーム画面に追加。

> GitHub Pagesの公開URLが有効になるまではエラーになります。GitHub Pagesへのアップロード・公開はユーザー操作が必要です。

## 問題の追加・編集・削除

単語帳の画面下部 **「問題の追加・編集・削除・復元」** から操作できます。

1. 追加／編集／削除を実施。削除は `archivedCards` に移動し、後から復元できます。さらに「完全削除」を選ぶと本文を消し、`retiredIds` にIDだけ残して再利用を防げます。
2. **「問題データを書き出す」** から `questions.json` をダウンロード。
3. GitHubリポジトリの既存 `questions.json` を新ファイルで **置換** してコミット。
4. 公開先URLをSafariで再表示すると全端末で新問題が使えるようになります。
5. 最新公開版が反映されたらローカル下書きは自動的に解消されます。

※端末で追加・編集した問題は、GitHubにアップロードするまでは **その端末だけの下書き** です。ChatGPTで既存 `questions.json` の追加・削除を行ってGitHubに反映する運用も可能です。複数端末の下書きを同時編集すると競合するため、編集・公開する端末を一つに決めることを推奨します。

## 安全なID・学習記録の扱い

- すべての問題には不変の `id` を付与。初期カードは `001`〜`150`。
- 追加カードは `nextId`（初期値151）を採番してインクリメント。削除しても番号を再利用しない。
- 問題の単純な誤字修正なら同じIDで編集できる。
- **問い・正答の意味が変わる場合** は削除→新規登録として新しいIDを使う。意味の異なる新問題への成績の誤引継ぎを防ぐ。
- 削除した問題は `archivedCards` へ移動し出題・集計対象から除外。保管中のカードは公開JSONから読むことができるため、本文も公開対象から消したい場合は「完全削除」を選ぶ。過去の成績はIDに紐づいて維持し、復元時に再表示される。
- 正答率は **正解回数 ÷（正解回数＋不正解回数）**。スキップは採点しない。
- ブラウザのローカルストレージに採点結果と端末下書きを自動保存する。公開後の問題変更でも同じ公開URL／ブラウザであれば従来の記録を維持できる。
- 以前の「150問固定版」の学習記録をインポートできる（`ap-kamokuB-150-progress` 形式）。同一オリジンであれば旧ローカルストレージキーからの自動移行も試みる。
- GitHub Pagesへアップロードしても学習記録はGitHubに自動同期されない。他端末へ移る前に **「学習記録を保存（JSON）」→「学習記録を読み込む」** を使う。
- ローカルストレージを消去したり公開URLを変更すると記録を取り出せなくなるため、定期的にバックアップを推奨する。

## JSONのスキーマ

```json
{
  "schemaVersion": 2,
  "deckId": "ap-kamoku-b",
  "title": "応用情報技術者試験 科目B デジタル単語帳",
  "revision": "2026-11-22T23:50:00+09:00",
  "nextId": 151,
  "categories": ["情報セキュリティ", "プロジェクトマネジメント", "サービスマネジメント", "経営戦略", "システム監査"],
  "cards": [{"id":"001","category":"情報セキュリティ","question":"...","answer":"...","explanation":"...","point":"..."}],
  "archivedCards": [],
  "retiredIds": []
}
```

`revision` は公開版更新の識別子。問題の追加・削除をするたびに新しい日時文字列へ更新します。学習記録は同じIDを保持する限り影響を受けません。
